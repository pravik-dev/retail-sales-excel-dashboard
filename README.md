# 🛒 Retail Sales Analysis Dashboard — Excel

An interactive Excel dashboard built to analyze 1,000+ retail transactions and extract meaningful business insights.

---

## 📊 Dashboard Preview

> *(See screenshots in repository)*

---

## 🎯 Project Objective

To analyze retail sales data and identify key trends in revenue, product performance, and customer demographics using Microsoft Excel.

---

## 🔧 Tools Used

- Microsoft Excel
  - Pivot Tables
  - Pivot Charts
  - Slicers (Interactive Year Filter)
  - YEAR(), SUM(), SUMIF() formulas
  - Data Cleaning

---

## 📁 Dataset

- **Source:** Kaggle — Retail Sales Dataset
- **Size:** 1,000 transactions
- **Columns:** Transaction ID, Date, Customer ID, Gender, Age, Product Category, Quantity, Price per Unit, Total Amount

---

## 📈 Key Insights

- 💰 **Total Revenue:** ₹456,000
- 🏆 **Top Category:** Electronics (₹156,905)
- 📅 **Peak Sales Month:** May
- 👥 **Gender Split:** Female 51% — Male 49%
- 🛍️ **Female customers** dominate Beauty category
- 📱 **Male customers** lead in Electronics purchases

---

## ✅ Features

- Category-wise Revenue Bar Chart
- Monthly Sales Trend Line Chart
- Gender-wise Sales Pie Chart
- Interactive **Year Slicer** (2023/2024)
- KPI Box — Total Revenue, Avg Order Value, Total Transactions, Top Category
